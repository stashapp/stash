Stash has changed how it calculates perceptual hashes (phashes) for videos of 2.5 minutes or less. Sampling 25 frames from a short video produces a repetitive image that hashes poorly, which caused unrelated short videos to be treated as duplicates and to match the wrong scenes when tagging.

**This migration deletes the existing phashes for all videos of 2.5 minutes or less**, since they were generated with the old algorithm and cannot be compared with the new ones. Run the **Generate** task with the **Video perceptual hashes** option afterwards to regenerate them. You do **not** need to enable `Overwrite existing files` — the affected videos no longer have a phash, so they will be picked up automatically.

Until stash-box instances have collected phashes generated with the new algorithm, short videos may not match by phash when tagging. Matching by title or by another fingerprint still works, and submitting fingerprints after a match will populate the new phashes.
