This migration introduces the user system. 

If you currently have credentials configured, these credentials will be migrated to the new user system. It is recommended to re-set the password to convert it to the more secure storage format. A backup of the current `config.yml` will be created in the same directory with the name `config.yml.86.<date and time>`. The exact filename is written to the log. 

Stash now rejects requests from public IP addresses unless the `public_access` configuration option is enabled. If you currently have credentials configured, `public_access` will be enabled so that the system remains accessible from the public internet as it was before the migration. If you do not need public access, you may disable it after the migration is complete.

If you do not have credentials configured, a default user will be created with the username `admin` without a password. You may rename the user and optionally set a password after the migration is complete. While the user has no password, any connections will be logged in automatically.

Ratings, favourites, o-counters, play history, resume times and saved filters are now stored separately for each user. Existing values are assigned to the migrated user. Other users start with no ratings, favourites, history or saved filters of their own.

The `organized` and `ignore auto tag` flags remain shared between all users, and may only be changed by administrators.
