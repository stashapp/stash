This migration introduces the user system. 

If you currently have credentials configured, these credentials will be migrated to the new user system. It is recommended to re-set the password to convert it to the more secure storage format. A backup of the current `config.yml` will be created in the same directory with the name `config.yml.85.<date and time>`. The exact filename is written to the log. 

If you do not have credentials configured, a default user will be created with the username `admin` without a password. You may rename the user and optionally set a password after the migration is complete. While the user has no password, any connections will be logged in automatically.
