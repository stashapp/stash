# Gallery People — unfinished prototype

This directory is a saved feasibility draft, **not an installable plugin**. Its YAML currently references frontend files that have not been implemented. Do not copy it into your live Stash plugin directory.

The [compatibility plan](../../docs/GALLERY_PEOPLE_PLAN.md) and [checkpoint status](../../docs/GALLERY_PEOPLE_STATUS.md) describe the agreed product and remaining work. In particular, the final workflow analyzes only selected images and includes appearance tagging; this prototype does not yet implement those requirements.
